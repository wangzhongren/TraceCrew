# 修复「回答被吞」误判——字数徽章单位错误与完成态缺失（呈现层）

> 状态：**诊断完成，修复方案待客户确认**（呈现语义变更按惯例呈批）。复现：`/tmp/b2r/` 窗口守望器已在运行（空闲窗口自起自有实例复跑同场景，任一完成/失败均有标记）；复现结果将补录。
> 结论一句话：**回答从未被吞**——卡片一直持有完整回答；是徽章把「≈1400 字的回答」显示成「14 字」，加上完成后一直亮着「思考中」的紫色徽章与旋转弧，让界面看起来像只收到了十几个字的碎片。

## 1. 立案证据（协调者提供 + 本上下文补证）

客户原话「这个修复一下」（截图：4 张 PM 卡，徽章 14字/15字/41字/3字）。

| 请求 | 模型末轮产出 | 卡片徽章 |
| --- | --- | --- |
| 1（抖音链路，35 工具轮后） | 1408 字 | 14字 |
| 2（单纯想了解现状） | 1556 字 | 15字 |
| 3（你怎么不给我画图啊） | 4159 字 | 41字 |
| 4（你应该让 mapper 画图啊） | 355 字 | 3字 |

现场日志（客户实例 `processStream`）：四次末轮均为「无操作 + 含终态标记（`<done/>` 或 `<final/>`）」，流正常收尾；末轮完整文本进入 `done.message`。

## 2. 根因（锁到文件:行）

**R1【高 · 直接误导】字数徽章单位错误** —— `frontend/src/components/ChatPanel.tsx:1010`：

```ts
statusLabel = `${Math.round(entry.text.length / 100)}${t('chat.chars')}`;
```

数值 = 字数 ÷ 100（四舍五入），后缀却是「字」/`chars`/`文字`/`자`。四请求全吻合：1408−( `<done/>` 7 字符)−尾部空白 ≈ **1399 → round(13.99)=14**；1546 → **15**；4149 → **41**；345 → **3**。即「14字」的真实含义是**约 1400 字**。

**R2【高 · 状态缺陷】完成后永无终态** —— `ChatPanel.tsx:1001-1010`：PM 类「纯文本卡」没有 `result`，`isThinking` 恒为真 → 流结束后仍保持「思考中」紫色胶囊 + 旋转弧（截图中徽章为紫胶囊、卡片圆点带旋转弧，均与该路径一致），界面没有任何「✓ 完成」信号。

**R3【观察 · 非缺陷】截图中卡片为折叠态** —— chevron 朝下 = `expanded=false`（`ChatPanel.tsx:1036`，用户点击折叠；代码无自动折叠）。折叠时仅见「PM ｜14字 ｜∨」一行，恰是客户截图的观感；展开即见完整回答（由 R1 数值反证 `entry.text` 即完整回答，展开渲染该字段）。

**排除项**（协调者列出的四个疑似层逐一排除）：
- 服务端 `done.message` **完整**（日志 + E 系列 `t2a-pm` 留档：`done.message` ≈ token 累积，仅去标记）；
- `cleanDoneMessage`（agent.ts:723）**仅剥标记、不截断**；
- 前端 `applyDoneMessage`（ChatPanel.tsx:172）**正确**：以完整回答替换流式累积文本（其替换后的长度恰为徽章数 ×100 的反推源）；
- **「卡片字数统计源」= 命中**（R1/R2 即此层）。

## 3. 修复方案（待客户确认）

| # | 内容 | 位置 | 说明 |
| --- | --- | --- | --- |
| F1 | 徽章显示**完整字数**：运行中 `思考中 · 1401字`；完成 `✓ 完成 · 1401字` | `ChatPanel.tsx:1010` 一带（既有 i18n 键 `chat.thinking`/`chat.done`/`chat.chars`，四语言包无需新增键） | 去掉 ÷100；单位诚实 |
| F2 | 流结束时标记**完成态**：PM/文本卡在 stream 收尾处写入 `status:'done'`，徽章转绿、旋转弧停止 | `ChatPanel.tsx`（`pmStream`/`agentLoop` 收尾处各一处 + AgentCard 状态分支） | 消除「永远在思考」 |

不做（明确排除）：自动展开/滚动（卡片默认展开，折叠是用户选择）；不动服务端/协议/日志。

**节点预估**：N1 agent-pipeline（ChatPanel.tsx，约 3 处小改）→ 本上下文核验 → 三/四门槛复跑（`npm test` 119/119、`tsc`、`build`、`check:electron`）+ 复现回归。
